# 웹 MVP 디자인 채택 기록

## 채택한 화면 구조

Claude Design 산출물은 현재 저장소에 별도 파일로 전달되지 않아, 프로젝트의 운영형 금융 UI 원칙과 기존 위험 경고 화면을 기준으로 MVP 구조를 확정했다. 공통 레이아웃은 데스크톱 좌측 내비게이션과 모바일 상단 가로 내비게이션으로 구성하고, 다음 네 개의 독립 URL을 제공한다.

- `/`: 대시보드. 포트폴리오 평가 요약, 위험 경고, 보유 종목의 짧은 현황을 보여 준다.
- `/holdings`: `holdingValuations`의 종목별 평가 표(모바일에서는 카드)를 제공한다.
- `/strategy-guides`: 보유 종목 가이드와 미보유 후보 가이드를 분리해 표시하고, 종목별 조회 불가 결과도 함께 보여 준다.
- `/settings`: 현재 존재하는 포트폴리오 위험 한도 조회·수정 UI를 둔다.

## 디자인 토큰과 컴포넌트 상태

- 배경은 연한 회색, 표면은 흰색, 본문은 짙은 회색을 사용해 장시간 읽기 편한 밀도 있는 화면으로 만든다.
- 상승 손익은 녹색, 하락 손익과 위험 경고는 적색으로 표현하되 텍스트 라벨과 금액/설명도 함께 제공한다.
- 카드, 표, 배지, 버튼은 동일한 얇은 테두리·작은 둥근 모서리·키보드 포커스 링을 사용한다.
- 모든 API 영역은 로딩, 오류, 비어 있음, 일부 종목만 조회 불가 상태를 구분해 표시한다.

## API 계약에 따른 보정

- 화면은 기존 `memberId=1`, `portfolioId=1` API만 호출한다. 인증이 도입되면 공통 컨텍스트로 교체한다.
- 평가 API가 제공하는 `market`, `ticker`, 수량, 평단가, 현재가, 매입금액, 평가금액, 평가손익, 수익률만 표시한다. API에 없는 거래소·추가 실시간 값·부분 실패 상세 수치는 만들지 않는다.
- 전략 가이드의 `referencePrice`는 최신 완료 주봉 종가이므로 `기준 가격`으로만 표기하며, 지정가·목표가·손절가·주문 CTA로 바꾸지 않는다.
- `SELL`은 `매도 검토`, `REDUCE`는 `비중 축소 검토`로 번역한다. 주문을 실행하거나 주문 초안을 생성하는 화면은 이 MVP 범위에 포함하지 않는다.
