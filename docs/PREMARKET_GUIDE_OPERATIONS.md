# 장전 가이드 운영 점검

장전 가이드는 미국 동부시간 기준 다음 거래일에 사용할 Track A 보유·후보 종목의
검토 결과를 저장한다. 자동 주문을 보내지 않으며, 사용자가 증권사에서 최종 판단과
주문 등록을 직접 수행한다.

## 자동 생성 설정

자동 생성은 실수로 외부 시세 API를 호출하지 않도록 기본값이 `false`다. 운영 환경에서
시장 데이터 제공자의 호출 한도와 포트폴리오 수를 확인한 뒤 다음 환경 변수를 명시적으로
설정한다.

```text
TRADEGUIDE_PREMARKET_SCHEDULER_ENABLED=true
TRADEGUIDE_PREMARKET_SCHEDULER_CRON=0 0 8 * * MON-FRI
```

스케줄러는 미국 동부시간으로 실행되며, 토요일·일요일과 초기 지원 범위의 미국 주요
휴장일에는 실행하지 않는다. 같은 포트폴리오·같은 거래일의 스냅샷은 재사용하므로
스케줄러가 중복 실행되어도 기본 실행에서 시장 데이터를 다시 조회하지 않는다.

## 수동 검증 시나리오

1. 전략 가이드 화면에서 `오늘 가이드 생성`을 누른다.
2. `생성 완료`, 기준일, 생성 시각, 보유·후보 건수를 확인한다.
3. 같은 날 다시 화면에 들어가거나 생성 버튼을 눌러도 기본 조회는 기존 스냅샷을 재사용하는지 확인한다.
4. 최신 시세를 다시 확인해야 할 때만 `오늘 가이드 다시 생성`을 눌러 강제 재생성을 수행한다.
5. 시장 데이터 요청 제한이 발생하면 기존 저장 가이드를 유지하고 `429 RATE LIMIT`과 재시도 대기 시간이 표시되는지 확인한다.
6. 일부 종목만 실패하면 상태가 `일부 조회 불가`가 되고, 성공한 종목과 조회 불가 종목이 각각 보존되는지 확인한다.

## API 계약

```text
GET  /api/members/{memberId}/portfolios/{portfolioId}/premarket-guide/today
POST /api/members/{memberId}/portfolios/{portfolioId}/premarket-guide/today
POST .../today?force=true
```

`GET`은 저장된 오늘 스냅샷만 조회하고, 없으면 `NOT_GENERATED`를 반환한다. `POST`는
오늘 스냅샷을 생성하며 이미 생성된 스냅샷은 기본적으로 재사용한다. `force=true`일 때만
시장 데이터를 다시 조회한다.

## 운영 전 확인

- 선택한 시장 데이터 제공자에 필요한 자격 증명과 연결 상태를 확인한다. Twelve Data를 선택했다면 `TWELVE_DATA_API_KEY`를 확인하고, Toss를 선택했다면 해당 계정 연결과 조회 권한을 확인한다. 비밀값 자체는 로그나 문서에 남기지 않는다.
- 여러 포트폴리오를 운영하는 경우 장전 시간대 제공자 호출량을 먼저 계산한다.
- 자동 생성 활성화 전 수동 생성·재사용·강제 재생성·429 보존 동작을 확인한다.
- 감사 화면의 `입력 근거 미검증`은 정상적인 현재 한계다. 자산별 캔들 근거와 HTTP 수신 기록이 있더라도 전체 원장·위험 설정 스냅샷이 묶이기 전에는 검증 완료로 해석하지 않는다. v1/v2 캔들 해시를 버전 확인 없이 직접 비교하지 않는다.
- Toss 최신 일봉의 정규장/장전 세션 범위는 2026-09-24 후속 관측 전까지 확정되지 않았다. 같은 날짜의 재조회 결과가 달라지면 원본 응답과 관측 시점을 먼저 대조한다.
- Track B와 MACD는 현재 운영 엔진에 포함하지 않는다. 별도 검증 게이트를 통과하기 전까지
  장전 가이드는 Track A 정책만 사용한다.
