# Track B 실데이터 워크포워드 1단계: 데이터 적합성 검증

## 목표

횡단면 모멘텀 검증 코어를 실제 주봉 가격 데이터에 재현 가능하게 연결한다. 이 단계의 목적은 데이터 수집·정규화·워크포워드 실행 가능성을 확인하는 것이며, Track B 채택 또는 실행 전략 구현이 아니다.

## 연구 범위

- 공개 Yahoo Finance 가격 이력만 사용한다. 앱의 시장 데이터 제공자, API 키, 운영 설정은 수정하지 않는다.
- 2015-01-01부터 실행 시점까지의 미국 대형주 **고정 연구 유니버스**를 사전에 코드·보고서에 명시한다.
- 유니버스는 point-in-time S&P 500 구성 데이터가 아니므로 `pointInTimeUniverse=false`로 기록하고, 결과를 S&P 500 전체 또는 실제 투자 성과의 근거로 해석하지 않는다.
- 편의적 종목 선택을 피하기 위해 시가총액·섹터 대표성 등 객관적이며 사전에 적힌 선정 기준을 사용한다. 특정 결과에 맞춰 종목을 교체하지 않는다.
- 주봉 데이터 원본, 정규화 결과, 수집 시각, URL 또는 요청 파라미터, 결측·실패 종목을 `research/data/` 아래에 재현 가능하게 저장한다. 실제 비밀값은 절대 저장하지 않는다.

## 변경 허용 범위

- `research/data/**`
- `research/reports/**`
- `research/scripts/**` 또는 `research/data/tools/**`

## 금지 범위

- `src/**`, `frontend/**`, `docs/**`(이 작업 명세 파일 제외), DB 마이그레이션, 애플리케이션 설정, 의존성, Git 변경
- `TradingStrategy`, `InvestmentTrack`, `StrategySelector`, API, 화면, 주문 기능 변경
- Track B 채택·활성화 선언

## 필수 산출물

1. 실행 방법과 입력·출력을 문서화한 재현 가능한 수집/실행 스크립트. 표준 라이브러리만으로 가능하면 새 의존성을 추가하지 않는다.
2. 고정 연구 유니버스의 원본 또는 정규화된 주봉 데이터와 메타데이터.
3. 비용 가정 최소 세 경우(왕복 20bp, 40bp, 57bp)를 명시해 실행한 워크포워드 결과 원자료.
4. 두 개 이상의 사전 고정된 비중첩 워크포워드 분할별 결과와 동일가중 매수 후 보유 비교.
5. `research/reports/track-b-walk-forward-data-feasibility.md`:
   - 데이터 출처·수집시각·유니버스 선정 기준
   - point-in-time 유니버스가 아니라는 한계
   - 비용 가정·분할·실행 파라미터
   - 결과표와 채택 게이트별 판정
   - 어떤 결과여도 Track B를 아직 채택하지 않는다는 명시
   - 다음 단계(시점별 유니버스 데이터 확보 또는 기각)의 권고

## 수용 기준

- 스크립트를 다시 실행하면 동일한 형식의 데이터와 결과를 생성할 수 있다.
- 외부 네트워크가 실패하거나 일부 티커가 누락되면 원인을 기록하고, 성공한 부분만으로 전체 전략 채택 결론을 내리지 않는다.
- 미래 가격이 과거 리밸런싱 순위에 들어가지 않는 기존 검증 코어를 사용하거나, 동등한 보호 장치를 코드와 테스트/검산으로 설명한다.
- 정규화 데이터의 중복 날짜·정렬·결측을 검사하고 결과에 기록한다.
- 결과가 미흡하거나 데이터 한계가 큰 경우에도 실패를 숨기지 않고 기각 또는 추가 검증 필요로 판정한다.
