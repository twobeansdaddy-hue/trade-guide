# 작업 계약: 장전 가이드 UI 독립 검증

- 작업 ID: `antigravity-premarket-ui-audit-20260915`
- 담당: Antigravity CLI
- 작업 모드: 읽기 전용 독립 검증
- 응답 언어: 한국어

## 목적

현재 구현된 장전 가이드와 증권사 연결 설정 화면이 실제 화면 폭에서 잘리지 않고, 버튼·메시지·카드의 배치가 일관적인지 독립적으로 점검한다.

## 허용 범위

- 읽기: 저장소 전체
- 실행: 테스트·빌드·브라우저 점검 명령
- 수정: 금지
- 커밋·푸시: 금지

## 검증 대상

1. `/strategy-guides`의 장전 가이드 생성·재조회·저장 결과 영역
2. `/settings`의 등록된 증권사 연결 카드와 세 개의 액션 버튼
3. 데스크톱, 768px, 430px, 390px에서 다음을 확인한다.
   - 수평 스크롤, 잘린 텍스트, 겹침이 없는가
   - 메시지 노출 전후에도 폼과 버튼이 불필요하게 흔들리지 않는가
   - 버튼의 높이·폭·위험 상태 색상이 일관적인가

## 완료 기준

- 재현 가능한 결함은 URL, 화면 폭, 사용자 동작, 관찰 결과, 관련 파일·선택자 후보와 함께 기록한다.
- 결함이 없다는 판단도 실제 확인한 URL·화면 폭과 함께 기록한다.
- 코드와 문서는 변경하지 않는다.
