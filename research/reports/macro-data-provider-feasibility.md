## 확인 방법과 실제 결과

### 지수 / VIX / 원자재 — Yahoo Finance (기존 방식 재사용)

Track A-KR 조사와 동일한 방식(공개 v8 chart API, 로그인/키 불필요)으로 실제 호출했다.

| 심볼 | 대상 | 첫 데이터 | 마지막 데이터 |
| --- | --- | --- | --- |
| `^GSPC` | S&P 500 | 1990-01-01 | 2026-09-16 |
| `^KS11` | KOSPI | 1996-12-08 | 2026-09-17 |
| `^VIX` | VIX | 1990-01-01 | 2026-09-16 |
| `GC=F` | 금 선물 | 2000-08-28 | 2026-09-17 |
| `CL=F` | WTI 원유 선물 | 2000-08-21 | 2026-09-17 |

지금까지 Track A/B/C 리서치가 이미 의존해 온 데이터 경로와 동일한 제공자라 신규
통합 비용이 거의 없다.

### 금리 / 인플레이션(미국) — FRED

FRED의 공개 CSV 다운로드 엔드포인트(`fred.stlouisfed.org/graph/fredgraph.csv?id=<SERIES>`)는
API 키가 필요 없다. 다만 이번 조사에서 `User-Agent`를 `"Mozilla/5.0 (research script)"`
같은 설명적 문자열로 보내면 서버가 거부했고, 일반적인 `curl` 기본 UA나 빈 UA로는
정상 응답했다 — 문서화되지 않은 봇 차단 휴리스틱으로 보이며, 운영 통합 시 이 점을
유의해야 한다.

| Series ID | 대상 | 첫 데이터 | 마지막 데이터 |
| --- | --- | --- | --- |
| `DGS10` | 미국 10년물 국채금리 | 1962-01-02 | 2026-09-15 |
| `FEDFUNDS` | 연방기금금리 | 1954-07-01 | 2026-08-01 |
| `CPIAUCSL` | 소비자물가지수(CPI) | 1947-01-01 | 2026-08-01 |
| `DCOILWTICO` | WTI 현물 유가 | 1986-01-02 | 2026-09-15 |

**중 발견)**: 신용스프레드의 더 표준적인 지표인 `BAMLH0A0HYM2`(ICE BofA 하이일드
옵션조정스프레드)를 먼저 시도했으나, FRED가 ICE 데이터 재배포 라이선스 제약으로
**2023-09-18 이후 데이터만 제공**했다(그 이전 구간은 접근 불가) - 장기 워크포워드
백테스트에는 쓸 수 없다. 대체로 `BAA10Y`(Moody's Baa 회사채 스프레드, 1986~전
구간 확보)를 신용스프레드 프록시로 사용했다 - 투자등급 채권 기반이라 하이일드
스프레드와 신용위험 민감도가 다를 수 있다는 한계가 있다.

### 공시(미국) — SEC EDGAR

`data.sec.gov`의 구조화 제출 이력 API(`/submissions/CIK<번호>.json`)를 애플(CIK 0000320193)
로 실제 호출해 200 OK를 확인했다. API 키는 불필요하지만, SEC 정책상 `User-Agent`에
연락 가능한 식별 정보(회사명·이메일 등)를 포함해야 하며, 이를 포함하지 않은 요청은
`www.sec.gov` 쪽에서 403으로 거부됨을 함께 확인했다(운영 통합 시 프로젝트 식별 UA를
설정해야 한다는 실무 제약).

### 뉴스 — Finnhub 무료 티어 (기존 키 재사용)

- **일반 뉴스**(`/news?category=general`): 실제 호출해 최신 100건을 확인했다. 날짜
  범위를 지정하는 파라미터가 없어 "지금 기준 최신 뉴스"만 가져올 수 있다 — 과거
  특정 시점의 시장 뉴스를 재구성(백테스트)하는 용도로는 쓸 수 없다.
- **종목별 뉴스**(`/company-news?symbol=&from=&to=`): 날짜 범위를 지정할 수 있어
  백테스트에 더 적합해 보였으나, 실제로 AAPL 기준 구간을 좁혀가며 확인한 결과
  **약 1년 전(구체적으로는 350~400일 전 사이) 이전 구간은 데이터가 0건**이었다
  (200일 전 236건, 300일 전 245건, 350일 전 219건, 365일 전 108건, 400일 전 0건).
  무료 티어의 비공개 이력 제한으로 보인다. 즉 뉴스 기반 신호는 **최근 1년 정도의
  실시간/준실시간 운영에는 쓸 수 있지만, 여러 해에 걸친 워크포워드 백테스트(Track
  A/B가 지금까지 해 온 방식)에는 무료 티어로 쓸 수 없다.**

### 국내 금리·인플레이션·공시 — 키 발급이 먼저 필요 (보류)

한국은행 ECOS(`ecos.bok.or.kr`)와 금융감독원 DART(`opendart.fss.or.kr`)는 둘 다 접속은
됐지만(루트 URL 200 OK), 실제 데이터 조회에는 무료 API 키 발급이 필요하다. 계정 생성은
사용자 대신 수행할 수 없는 작업이라(개인정보·본인 확인이 필요한 외부 계정 생성),
**사용자가 두 사이트에서 직접 무료 키를 발급**해야 다음 단계(실제 이력 깊이·조회
가능 지표 확인)로 진행할 수 있다. Finnhub 무료 키를 사용자가 직접 발급했던 것과
동일한 절차다(`research/reports/track-b-fundamental-data-provider-evaluation.md`).

## Tier 3 판정에 대한 의미

`research/STRATEGY_ENGINE_POLICY.md`의 분류 프레임에서 Tier 3(가격+펀더멘털+매크로
연계 확인)로 자산을 올리려면 매크로 데이터가 실제로 확보돼야 한다. 이번 조사 결과:

- **미국 자산(Track A-US, Track B-US)**: 지수·VIX·금·유가·금리·인플레이션·공시까지
  전부 무료·즉시 사용 가능한 경로를 확인했다. **데이터 확보 관점에서는 Tier 3로 올릴
  준비가 됐다** — 다만 이 데이터를 실제 전략 신호로 어떻게 연결할지(가설 설계, 백테스트)
  는 별도 작업이며 이번 조사 범위가 아니다.
- **국내 자산(Track A-KR, Track B-KR)**: 지수(KOSPI)는 확보했지만 금리·인플레이션·공시는
  사용자의 키 발급이 선행돼야 한다. 그 전까지는 Tier 1에 머문다.
- **뉴스는 모든 자산에 공통 제약**이다 — 실시간 가이드(목표 B의 프리마켓/본장/애프터
  마켓 시점 판단)에는 쓸 수 있지만, 그 신호가 과거에 유효했는지 검증하는 백테스트에는
  무료 티어로 1년 이상 거슬러 갈 수 없다. 이는 목표 (B) 엔진을 설계할 때 "백테스트로
  검증된 규칙"과 "실시간에만 쓸 수 있고 장기 검증은 못 하는 신호"를 구분해야 함을
  뜻한다 — `research/STRATEGY_ENGINE_POLICY.md`의 "검증과 활성화 조건"(학습·검증 구간
  분리, 워크포워드 검증)과 정면으로 부딪히는 제약이다.

## 다음 단계 제안

1. **사용자 결정 필요**: 한국은행 ECOS, 금융감독원 DART 무료 API 키를 발급할지 여부.
   발급하면 국내 자산도 금리·인플레이션·공시 축에서 Tier 3 조사를 이어갈 수 있다.
2. 미국 자산부터 먼저 매크로 연계 가설을 설계한다 — 데이터는 이미 확보됐으므로,
   막연히 "매크로를 본다"가 아니라 구체적 가설(예: VIX 급등 구간에서 Track A 진입
   규칙을 어떻게 조정할지)을 사전 등록하고 검증하는 다음 리서치 항목으로 넘어간다.
3. 뉴스 기반 신호는 백테스트 불가 제약을 감안해, 처음부터 "장기 검증된 규칙"이
   아니라 "실시간 참고 정보"로 범위를 좁혀 설계하는 것이 현실적이다.
