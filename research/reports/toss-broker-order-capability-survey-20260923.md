## 1. 일반 주문 (`POST /api/v1/orders`, 정정·취소)

| 항목 | 문서 내용 | 설계 영향 |
|---|---|---|
| 호가 유형 | `LIMIT`, `MARKET` | 손절 트리거는 일반 주문으로 표현 불가 → 조건주문 필요 |
| 유효 조건(TIF) | `DAY`(기본, 정규장 종료 시 미체결분 자동 취소), `CLS`(미국 + LIMIT = LOC), `OPG`(국내 시가단일가) | 다일 유효(GTC) 주문은 문서에 없음 |
| 수량 | 정수. 소수점은 미국 시장가 매도·금액 주문만, 정규장 시작~종료 1시간 전 | 계산 코어의 정수 수량 가정과 일치 |
| 정정 | 국내: 가격·수량. **미국: 가격만**(수량 정정 불가) | 미국 잔여 수량 축소는 취소 후 재주문 |
| 주문 가능 시간 | 매매 시스템 시간을 그대로 따르며 불가 시간이면 `422 order-hours-closed` | 세션 판단은 장 운영 정보 API로 |
| 멱등성 | `clientOrderId`(10분 유효) | 재시도 중복 방지에 활용 가능 |
| 사전 요건 | 미국 레버리지·인버스 ETF는 앱에서 투자자 성향·위험 고지 등록이 끝나야 함(`422 prerequisite-required`) | SOXL·TQQQ 주문 전 계정 확인 필요 |
| 고액 주문 | 1억원 이상 확인 플래그, 30억원 이상 거부 | — |
| 부분 체결 | 주문 1건이 1행이며 여러 체결은 평균가·총수량으로 합산. 부분 체결 후 취소 시 체결분 유지. 건별 체결 이벤트는 웹소켓 `personal:order` | 계획 코어의 "체결 후 상태 버전 증가·계획 무효화"는 주문 상세 폴링 또는 웹소켓으로 감지해야 함 |
| 거래소 지정 | 국내는 통합(SOR)만, KRX·NXT 지정 불가 | — |

## 2. 조건주문 (`/api/v1/conditional-orders`)

| 항목 | 문서 내용 |
|---|---|
| 타입 | `SINGLE`(한 조건), `OCO`(두 조건 동시 감시, 하나 충족 시 나머지 자동 취소), `OTO`(첫 조건 체결 후 둘째 감시 시작) |
| OCO 제약 | 두 조건 모두 **매도**, 첫 감시가 > 현재가 > 둘째 감시가, **지정가만** |
| OTO 제약 | 첫 조건 **매수**, 둘째 **매도**, 지정가만 |
| 수량 | 그룹 공통 1개 값. OCO·OTO의 두 조건은 **같은 수량**을 쓴다 |
| 만료 | `expireDate` 필수. 만료일까지 미충족 시 자동 만료 |
| 발동 세션 | 국내: **KRX 정규장에서만**. 미국: **거래 가능한 모든 시간대**(프리·애프터·데이마켓 포함). 감시 거래소 선택 불가 |
| 정정·취소 | 수정(`/modify`)·취소(`DELETE`) 지원 |
| 부분 체결 시 처리 | **문서 불명**: 트리거된 지정가 주문이 일부만 체결될 때 OCO 반대편 취소 시점, 다른 체결로 보유 수량이 줄었을 때 조건주문 수량의 자동 조정 여부 |

## 3. 세션과 장 운영 정보

- 미국 장 운영 정보는 4개 세션 `dayMarket`(토스 데이마켓, 예시 09:00~16:50 KST), `preMarket`, `regularMarket`, `afterMarket`을 KST로 제공한다. 휴장 시 모두 null. 전일·당일·익일 3영업일.
- 국내는 KRX+NXT 통합 기준 `preMarket`(NXT)·`regularMarket`·`afterMarket`. 거래소별 시간은 제공하지 않는다. 장전·장후 시간외종가는 제외되며 Open API가 지원하지 않는 호가 유형이다.
- 일반 주문에는 세션 지정 파라미터가 없다. 실제 접수 가능 세션(특히 미국 데이마켓·프리·애프터)은 매매 시스템 규칙을 따르며 **계정에서 확인이 필요**하다.

## 4. 시세(캔들) 규격과 한계

| 항목 | 문서 내용 | 엔진 영향 |
|---|---|---|
| 봉 단위 | `1m`, `1d`만 | 주봉은 앱에서 일봉 집계(현 구현과 일치) |
| 페이지 | 최대 200개, 최신순, `before`(inclusive) 페이지네이션 | 2026-09-23 관측과 일치 |
| 타임스탬프 | `1m`은 **봉 종료 시각**, `1d`는 거래일 0시 | 수집 계약의 `eventAt`(봉 종료) 정의와 1m은 바로 맞음 |
| **이력 시작** | **국내 2022-11-23 이후, 미국 2021-11-30 이후.** 그 이전은 제공하지 않음 | 장기 백테스트(위기 구간 포함) 데이터로는 부족. 미국 약 4.8년·국내 약 3.8년 |
| 상장폐지 종목 | 조회 불가(`404`) | 과거 시점 종목군(PIT) 재구성 불가 → 생존 편향 |
| 수정주가 | `adjusted=false`여도 제공 시작 이전 구간은 이미 조정된 값만 보유. 조정 시 거래량도 나눔 | 당시 명목 가격 복원은 제공 시작 이후만 |
| 사후 정정 | 과거 캔들 사후 정정 없음(기업행위 조정 제외). 미국 1분봉 이상치 필터링·거래소 정정 반영 없음 | 이상치 정제 규칙이 필요 |
| 미국 시세 원천 | 일부 미국 거래소 기준, **NBBO가 아님**. 세션별로 원천이 다를 수 있음 | Twelve Data 등 통합 시세와 시가·저가·거래량 차이가 날 수 있음 |
| **미국 일봉 OHLC** | **정규장 공식 종가.** 프리·애프터·데이마켓 체결은 일봉 OHLC에 포함하지 않음. 거래량은 종합 거래량이라 시간외 체결이 포함될 수 있음 | 아래 5절 참고 |
| 국내 1분봉 | 08:01~20:00(프리~애프터) 봉 제공. 1분봉 거래량 합계는 일봉과 다를 수 있음(일봉은 시간외·대량 매매 포함) | 1분봉으로 일봉 재구성 불가 |
| 호출 한도 | 차트 `MARKET_DATA_CHART` 초당 20회. 주문 `ORDER` 초당 10회, 조건주문 초당 5회 등 클라이언트×그룹 단위 | 소표본 실측은 한도 안에서 가능 |
| 토큰 | 클라이언트당 유효 토큰 1개, 재발급 시 직전 토큰 즉시 무효 | 관측 도구 실행 시 앱 중지 필요(기존 관측과 같음) |
| 이용 조건 | 데이터 저장·재배포·상업적 이용 조건은 **API 문서에서 확인하지 못함** | 기존 미확정 항목(U-15 WTS 약관)과 함께 운영 전 확인 |

## 5. 2026-09-23 일봉 세션 범위 1차 관측과의 관계

`docs/design/GUIDE_INPUT_OBSERVATION.md`의 1차 관측은 가장 최근 마감일(09-22) 토스 일봉의 시가·저가와 거래량이 Twelve Data와 다르다는 점에서 "최신 일봉이 장전 거래를 포함한 잠정값"이라는 가설을 세웠다. 공개 FAQ는 미국 일봉 OHLC에 시간외 체결을 넣지 않고 거래량만 종합 거래량일 수 있다고 적는다. 따라서 **가격 차이는 장전 거래 포함보다 "NBBO가 아닌 일부 거래소 원천" 또는 공급자 간 최신일 확정 시점 차이로 설명될 가능성이 있고, 거래량 1.5~2.3% 초과는 문서와 부합한다.** 반면 관측 시각(정규장 개장 전)에 09-23 일봉이 이미 OHLC 값을 가졌던 점은 문서만으로 설명되지 않는다. 결론은 2026-09-24 05:00 KST 이후 2차 관측으로 판단하며, 그 전에는 가설을 확정하거나 보정 규칙을 넣지 않는다.

## 6. 설계(`trade-guidance-engine-design-2026-09-21.md`) 대비 시사점

- **가격대별 다단계 계획의 예약 가능 범위가 좁다.** 설계 8절 예시(3주 익절 지정가 + 1주 위험 축소 하향 조건 + 잔여 청산)는 수량이 서로 다르므로 하나의 OCO로 표현할 수 없다(OCO는 두 조건 공통 수량). 별도 조건주문 여러 개로 걸면 서로 배타·잔여 수량 자동 축소가 보장되지 않는다(문서 불명). 설계 원칙대로 **확인 전까지 복합 계획은 "예약 불가 / 수동 검토"로 표시**하고, 브로커 예약은 `SINGLE` 또는 **같은 수량의 익절·손절 OCO**(보유 전량 대상)로 제한하는 것이 안전하다.
- **OTO는 매수 후 매도 1개만** 연결하므로 진입 후 익절·손절을 동시에 거는 완전한 브래킷은 문서상 없다.
- **미국 조건주문은 시간외 세션에서도 발동한다.** 유동성이 얇은 프리·애프터·데이마켓에서 트리거될 수 있으므로 설계의 세션 계약(세션별 독립 검증)에서 위험으로 표시해야 한다. 국내는 KRX 정규장에서만 발동한다.
- **미국은 수량 정정이 불가**하므로 부분 체결 후 잔여 수량 조정은 취소 후 재주문(상태 버전 증가 후 재계산)으로 처리해야 한다. 계산 코어의 "체결 후 계획 무효화" 원칙과 맞다.
- **데이터 측면에서 토스는 D2(최근 몇 년의 세션 분봉)의 후보지만 D1 장기 검증에는 부족하다.** 이력 시작일(미국 2021-11-30)과 상장폐지 종목 부재 때문에 위기 구간 스트레스와 PIT 종목군은 다른 공급원이 필요하다. 1분봉의 실제 이력 깊이·세션 포함 범위는 실측으로 확인한다.

## 7. 사용자 계정 확인이 필요한 항목

1. SOXL·TQQQ 등 레버리지 ETF의 사전 요건 등록 완료 여부(앱).
2. Open API 일반 주문이 미국 데이마켓·프리·애프터 세션에 접수되는지(`order-hours-closed` 여부).
3. 조건주문 OCO의 트리거 주문이 부분 체결될 때 반대편 조건 취소 시점과, 다른 체결로 보유 수량이 줄었을 때 조건주문 수량 처리.
4. 조건주문이 미국 시간외 세션에서 발동했을 때 생성되는 주문의 유효 세션.
5. Open API 시세의 저장·연구용 활용 가능 범위(약관).
