# 세션 가이드 백데이터 재생 게이트 v1

성격: **연구용 오프라인 시점 검사**. 추천 알고리즘, 체결 시뮬레이터, 수익률 계산기, 운영 가이드가 아니다.

## 입력과 판정

`replay_gate.validate(dataset, decision)`에 수집 근거가 보존된 preflight 데이터셋과 가이드 판단 1건을 넣는다. 판단에는 `instrumentId`, `session`, `decisionAt`, `portfolioKnownAt`, 참조한 `barIndices`, 신규 후보 평가 시 `requiresPitUniverse=true`가 필요하다. 반환은 `PASS`, `WARN`, `BLOCKED`와 사유 코드다.

이 게이트는 참조한 봉만 골라 `requireObservedProvenance=true`, `strict=true`, `cutoffAt=decisionAt`으로 기존 데이터 검사기에 넘긴다. 따라서 수신 시각·봉 종료·포트폴리오 상태가 판단 이후이거나, 종목/세션이 다르거나, 신규 후보가 시점별 종목군 근거 없이 선택됐으면 차단한다. 참조하지 않은 미래 봉은 이전 판단을 무효화하지 않는다.

## 통과의 의미와 남은 증거

- `PASS`는 **선언된 참조 봉과 포트폴리오 시각의 구조적 정합성**만 뜻한다. 봉 목록이 실제 모델이 읽은 모든 입력인지, `portfolioKnownAt`이 실측인지, 종목군 선언이 진짜 PIT인지 검사기가 독립적으로 증명하지 못한다. 모델 입력·상태 스냅샷의 불변 식별자와 생성 로그가 다음 필수 작업이다.
- 실제 SOXL 캐시에는 과거 응답 수신 시각이 없으므로 이 게이트에 사용 가능한 과거 장전 가이드를 소급 생성할 수 없다. 새로 받아오는 오래된 일봉의 수신 시각은 **지금**이지 과거 장전이 아니다.
- 가격·수량 생성 규칙은 아직 채택되지 않았다. 가이드 출력 자체의 품질은 여기서 평가하지 않는다.
- 체결 평가에는 해당 시점 명목 가격, 거래 가능 세션, 호가/체결 자료 또는 보수적 체결 모델, 수수료·세금·슬리피지·미체결/부분체결 규칙이 따로 필요하다. OHLC의 고가·저가에 닿았다는 이유만으로 체결을 확정하지 않는다.
- 전략 선택에 사용한 구간과 최종 평가 구간을 분리하고, 국내·미국 및 위기/호황 구간을 별도로 보고한다. 위기 구간을 삭제해 성과를 높이는 것은 허용하지 않는다. 반복 선택의 백테스트 과최적화 위험은 [Bailey 등 연구](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=2326253)에서 다룬다.

## 다음 구현 순서

1. 모델이 읽은 가격·기본적 지표·거시·심리 데이터 각각에 대해 `source`, 원본 시각, 실제 이용 가능 시각, 빈티지, 변환 버전, 참조 ID를 보존한다. 재생 게이트는 현재 OHLC 봉만 다룬다.
2. 포트폴리오 잔고·현금·계좌별 예약 주문·분할/배당의 시점별 스냅샷을 보존해 `portfolioKnownAt` 선언을 독립 대조한다.
3. 가격·수량 후보 생성 규칙을 명시하고 먼저 고정한다. 학습/검증/미사용 평가 구간을 나눠 재생하며 거래 비용과 미체결을 포함한다.
4. 보유 종목과 신규 후보를 분리 평가하고, 미국/한국의 장전·애프터·본장 가능 범위를 데이터 권리와 세션별 유동성에 맞게 판정한다.
5. 통과 뒤에도 일정 기간 실거래 없이 가이드만 기록해 사전 등록한 평가 지표와 비교한다. 그 전에는 사용자에게 검증된 매매 추천으로 표시하지 않는다.

검증: 합성 데이터 기반 데이터 검사기·수집기·재생 게이트 unittest **110개 통과**, 계산 코어 **48개 통과**. 실제 시장 데이터 백테스트나 수익성 검증은 수행하지 않았다.
